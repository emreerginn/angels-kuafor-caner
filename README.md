# Angels Bayan Kuaförü Caner — web sitesi demosu

Edirne'deki Angels Bayan Kuaförü Caner için tek sayfalık, üç dilli (TR / BG / EL) web sitesi demosu.

- `src/template.html`: düzenlenecek asıl dosya
- `tools/build.py`: şablondan `site/` klasörünü üretir (Python + Playwright)
- `site/`: yayına giden statik dosyalar (GitHub Pages bu klasörü yayınlar)

Online randevu bölümü tanıtım amaçlıdır; randevu kaydetmez.
